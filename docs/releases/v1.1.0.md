# Video Account Distiller 1.1.0

Status: staged on 2026-09-02; not tagged or published.

This candidate adds the native Windows desktop update path, the exact
`VideoAccountDistiller-Setup-1.1.0-win64.exe` installer contract, richer desktop task progress and
waiting feedback, native Qwen cloud-video understanding, and the Qwen-video plus DeepSeek
knowledge-distillation workflow. Package and Skill versions move together to `1.1.0`; persisted
schema, rubric, rule, and analysis-contract versions keep their existing values.

## Required release assets

- `video_account_distiller-1.1.0.tar.gz`

## Publication gate

Do not create or publish `v1.1.0` from this staged source alone. A real 7～14 day public-beta
campaign must target the installed `1.1.0` build, meet its date, machine, account, recovery, and
incident gates, then produce
`release-evidence/video-account-distiller-public-beta-1.1.0.zip`. The release audit must verify
that frozen evidence, the exact Windows installer name and executable format, all Python/Skill
artifacts, and the complete checksum manifest. Missing or synthetic evidence remains a hard
failure; it must not be replaced with a placeholder bundle.

## Upgrade boundary

The Windows installer keeps the existing application identity and installation directory so an
installed copy is updated in place. Project data is not rewritten automatically. Back up and
verify important projects before upgrading, and use the documented migration preview before any
explicit migration operation.
