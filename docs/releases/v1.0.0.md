# Video Account Distiller 1.0.0

The first stable release packages the completed Phase 0–7 workflow for production use on Python
3.11 or later.

## Highlights

- Import, validate, deduplicate, normalize, and query authorized video-account exports.
- Generate account-local robust metrics, samples, health reports, blind video analysis, comment
  analysis, account distillation, scoring, predictions, publication links, and retrospectives.
- Analyze local hotel MP4/MOV/MKV media without uploading it.
- Use opt-in authorized Feishu Bitable and Google Sheets adapters with bounded retry and
  credential-safe configuration.
- Inspect an installed environment with `distiller doctor --json` and report the installed version
  with `distiller --version`.
- Emit pipe-safe machine JSON on Windows, including when the project path contains Chinese text.
- Download the Python wheel/source archive and the separately installable standard Agent Skill zip
  from the same release, with one checksum manifest covering all artifacts.

## Production acceptance

The release wheel was installed into a new Python 3.11 environment on Windows and completed the
18-step operator workflow documented in `docs/production-acceptance-v1.0.0.md`. Acceptance covered
30 videos, 30 metric snapshots, 18 comments, report/distillation generation, and a user-supplied
hotel MP4. Final project validation reported zero errors and zero warnings.

## Compatibility and boundaries

- Existing Phase 0–7 projects remain compatible; artifact schema versions are unchanged.
- Online table adapters remain opt-in and require tenant-specific authorization acceptance.
- No browser scraping, login automation, CAPTCHA bypass, or automatic background scheduler is
  included.
