# Video Account Distiller 前端设计系统

## 产品方向

前端以“运营与分析工作台”为核心，而不是暴露底层工具和接口。所有页面共用同一套导航、
标题、工作区配置和状态语言，保留原有 FastAPI 业务接口与 Streamlit 运行方式。

主要体验目标：

- 日间主题是明亮、轻量的蓝紫数据工作台。
- 夜间主题使用炭黑、深灰和香槟金，强调稳重的商务科技感。
- 高频任务遵循“输入—配置—预检—执行—查看结果”的连续流程。
- API、模型和开发者信息退居次级区域，普通运营用户仍能理解。

## 全局结构

- 左侧栏：品牌、七个中文产品入口、折叠式连接配置和运行状态。
- 顶部栏：页面标题、说明、帮助、通知、浏览器持久化的日夜主题开关和用户占位。
- 主内容区：最大宽度 1480px；桌面采用多列数据卡片，窄屏自动减少列数。
- 通用组件：按钮、输入、选择器、开关、上传、卡片、指标、表格、标签、进度、
  Alert、Tabs、Stepper、Expander 和空状态均由共享 CSS token 驱动。

## 页面重构

- 工作台：KPI、最近任务、七日任务趋势、快速入口、运行能力、最近报告和待处理事项。
- 采集任务：采集来源、采集范围、内容理解、预检与执行四步工作流，并保留任务恢复、
  GPT 分析和 OpenKB 同步。
- 账号分析：账号输入、抽样报告、内容分析、提炼闭环和任务状态五步流程。
- 数据中心：统一筛选、主题化表格、CSV 导出、分页、空状态和导入来源记录。
- 数据导入：公开数据和授权私域导出双路径向导，展示文件准备、校验和标准化结果。
- 分析报告：筛选、卡片列表、Markdown/JSON 双视图、导出与重新生成。
- 系统设置：连接、AI 权限、运行状态和开发者入口分区，危险操作单独隔离。

## 主题与交互

主题由 CSS 自定义属性实现。顶部开关将选择写入 URL 查询参数和浏览器
`localStorage`，跨页面与重新打开应用时恢复。组件的 hover、active、disabled 和 focus
状态均使用对应主题 token；focus 状态保留可见轮廓，保证键盘操作可辨识。

业务请求、任务协议、数据模型和项目目录结构保持不变。新增页面呈现只消费现有接口，
避免把演示数据伪装成真实业务数据。
