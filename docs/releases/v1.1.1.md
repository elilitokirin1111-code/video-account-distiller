# Video Account Distiller 1.1.1

Status: staged on 2026-09-03; not tagged or published.

This patch candidate completes the desktop knowledge workflow introduced in 1.1.0. The WeKnora
page now discovers project accounts and presents account name, handle, and platform while keeping
the canonical `acc_*` ID available for selection, refresh, copy, and synchronization.

Per-video creative report v2 adds an executive summary, complete structure breakdown, evidence
coverage, dimension scoring, strengths, weaknesses, and prioritized improvements. Low-evidence
gates leave unsupported dimensions unknown or unscored instead of manufacturing certainty.

Cloud configuration now separates the Qwen native-video endpoint from the workspace-specific
Bailian MaaS endpoint used by DeepSeek V4 Flash text distillation. WeKnora creative-learning sync
uploads available per-video reports alongside the account result and records total and degraded
document counts.

## Required release assets

- `video_account_distiller-1.1.1-py3-none-any.whl`
- `video_account_distiller-1.1.1.tar.gz`

- `SHA256SUMS.txt`, covering every published binary and evidence asset

The Windows installer retains the stable AppId and previous installation directory for an in-place
upgrade. Project data, desktop settings, task history, and credential-manager secrets remain outside
the installation directory. Publication is still subject to the real public-beta evidence and
release-audit gates; a placeholder evidence bundle is not acceptable.
