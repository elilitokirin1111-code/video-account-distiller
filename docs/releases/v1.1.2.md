# Video Account Distiller 1.1.2

Status: staged on 2026-09-03; not tagged or published.

This patch makes the cloud-analysis, report, and knowledge-sync path production-safe for Chinese
operators. Per-video text analysis, comment intent, knowledge extraction, and creative breakdown
can use the selected cloud text provider consistently, while reader-facing Markdown translates
machine enums and warning codes into Chinese without changing the JSON contracts.

WeKnora documents now use the video title as their visible name. The canonical video ID remains in
metadata for stable retrieval and replacement. Sync rejects degraded artifacts, preserves older
complete documents when a new analysis is unusable, limits deletions to the exact account/video
scope, and never resolves a duplicate by deleting an unverified or manually uploaded document.

The release also fixes narrative runs that remained permanently marked as running, adds conservative
reconciliation for genuinely interrupted historical runs, keeps successful visual evidence when an
optional keyframe or audio step is degraded, normalizes content pillars for reports and sampling,
and improves low-transcript knowledge extraction with explicit visual/OCR evidence references.

Account knowledge now exports the newest cloud account-health, content-strategy, and growth-plan
analyses as three separately named Chinese reports instead of keeping only the newest cloud report.
Reader-facing reports also translate internal evidence-field paths and distinguish source-data gaps
(`未采集`, with the required upstream source) from model uncertainty. The underlying JSON values and
audit IDs remain unchanged.

the installation directory. Publication is still subject to the real public-beta evidence and
release-audit gates; a placeholder evidence bundle is not acceptable.
